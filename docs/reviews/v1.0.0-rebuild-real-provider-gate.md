## Product defects found and fixed during this gate (source → tests → repackage → reinstall → rerun)

1. **fs.read crashed the whole leg on directory reads** — Windows
   `read_bytes(dir)` raises PermissionError(13), which escaped as an unhandled
   internal error killing the task. Now a clean tool error the model can recover
   from (the model immediately self-corrected after the fix).
   `tests/unit/test_filesystem_tools.py::test_fs_read_directory_returns_tool_error_not_internal`.
2. **answer_predictor read scopes missed 交接/数据档案.json** while its own S0.3
   prompt instructs reading it — the leg was unsatisfiable as prompted.
   Registry fixed + `tests/unit/test_role_scopes.py`.

Regression at gate HEAD: **464 passed / 0 failed**, Ruff clean, sidecar + NSIS
rebuilt, silent reinstall, startup smoke exit 0. All real-gate runs (v4–v11)
