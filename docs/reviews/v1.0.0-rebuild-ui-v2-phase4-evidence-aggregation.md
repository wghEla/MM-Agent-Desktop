## Important nuance: forced kill vs normal lifecycle

The Phase-3 installed smoke records that forcibly killing the desktop process can leave old
sidecars until explicitly cleaned.  Normal application shutdown exits cleanly with zero
MM-Agent processes.

This does not invalidate the Phase-4 checklist because the product's supported normal
shutdown path and authenticated cancellation path are both cleanly proven.  A hard external
kill is not reclassified as graceful shutdown.
