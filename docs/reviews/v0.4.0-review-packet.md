## 4. Known limitations

1. S0 角色由 MockProvider 驱动（无真实 LLM）：Agent 流验证的是 Loop/权限/产物/门检接线，
   不是读题质量。真实 Provider 验证标 unverified。
2. S1 原型执行依赖 python.run 工具（v0.2 ProcessManager 路径）——测试中用 mock provider
   而非真实 Python 执行；真实原型脚本的 sandbox 隔离在 v0.5 红队测试中强化。
3. 三档 profiles 是配置数据（无 UI），角色分档通过 ROLE_REASONING_TIERS 映射到 AgentLoop reasoning 参数。
4. 需求追踪矩阵由机械代码生成（从题面契约提取），不依赖 LLM。
