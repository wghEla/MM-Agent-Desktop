## Root cause of the deferred read-path defect

The Installed Cancellation Gate had observed: the frozen installed sidecar
could WRITE a provider credential but failed to READ it back
("credential not found"), while Credential Manager (`CredEnumerate`) showed the
entry and the dev-tree unit round-trip passed.

Root cause (proven this round via a new non-secret diagnostics endpoint on the
installed sidecar):

```
ModuleNotFoundError: No module named 'win32timezone'
```

`win32cred` lazily imports `win32timezone` inside its CredRead path.
PyInstaller's static analysis misses that lazy import, so the frozen sidecar
simply lacked the module. The old `get()` collapsed every read failure into
`KeyError("credential not found")`, which is why the defect masqueraded as a
missing credential rather than a missing module.

## Source fixes (all regression-tested, repackaged, reinstalled before E2E)

1. **`scripts/build_sidecar.py`**: `--hidden-import win32timezone` added (the
   actual fix for the frozen read path).
2. **`mmagent/runtime/credentials.py`**: error taxonomy introduced —
   `CredentialNotFound` (winerror 1168) vs `CredentialReadError` (everything
   else, carrying the OS error / blob shape). An existing-but-unreadable
   credential can never again masquerade as missing. `describe()` returns a
   non-secret diagnostic (found/blob_len/sha256_prefix/blob_kind).
3. **`mmagent/sidecar/server.py`**: authenticated diagnostics endpoints
   `POST /diagnostics/credential` (non-secret probe) and
   `POST /diagnostics/credentials/enumerate` (target names only).
4. **`mmagent/providers/openai_chat.py`**: Test Connection now falls back from
   a 404/failed `/models` to a real minimal chat probe using the configured
   model (`max_tokens=1`), matching the `openai_compatible` behavior — relays
   without `/models` are no longer false negatives.

Focused tests added: `tests/unit/test_credentials.py` (cross-process round
trip in separate real processes, NOT_FOUND vs DECODE distinction, decode
taxonomy) and `tests/providers/test_provider_contracts.py`
(openai_chat /models-404 chat fallback + models-200 no-fallback). Full suite:
**462 passed / 0 failed**, Ruff clean.
