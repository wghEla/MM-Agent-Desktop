Date: 2026-09-29
Branch: `gpt/fidelity-rebuild`

## Decision

The remaining fidelity `PARTIAL` rows are **not automatically release blockers**.

The master specification requires a high-fidelity reimplementation, not byte-for-byte or
packaging-shape identity with the reference Skill.  The final completion condition is a
runnable Windows client, end-to-end pipeline, real `v1.0.0` tag, and no unresolved
external-review P0/P1.

This review therefore distinguishes:

- **release-integrity gaps** — must close before tag;
- **accepted fidelity partials** — implemented behavior exists and the remaining gap is
  exact upstream parity/evidence shape, not a known correctness/safety defect;
- **real-provider ceremonial evidence** — useful final proof but not a hidden source fix.
