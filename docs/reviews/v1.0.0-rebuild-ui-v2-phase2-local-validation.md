## 4. 本轮产品 bug 修复（验证暴露、最小改动）

**sidecar 工作区 create/open 错误降级为 500 空 body**：
`ProjectWorkspace.create/open` 抛 `FileExistsError`（"目标目录已有工作区结构"）/
`FileNotFoundError`（"不是 mmagent 工作区（缺 project.db）"），但 sidecar 只注册了
LookupError/ValueError/RuntimeError 处理器 → OSError 家族落到 FastAPI 默认 500 无 detail，
Dialog 只能显示 "500: Internal Server Error"。
修复：`mmagent/sidecar/server.py` 增加 `FileExistsError→409`、`FileNotFoundError→400`
两个异常处理器（detail 原文透出）；新增集成测试锁定两条错误语义。
修复后 UI 实测：重复创建显示 "409: 目标目录已有工作区结构: <路径>"，空目录打开显示
"400: 不是 mmagent 工作区（缺 project.db）: <路径>"，Dialog 均停留不关闭。
未触碰任何 Runtime 语义边界。
